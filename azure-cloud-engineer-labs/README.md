# AZ-104 Azure Administrator Lab

## Overview

This project is focused on hands-on practice for the Microsoft Azure Administrator (AZ-104) certification objectives.

The purpose of this lab is to build real Azure administration experience while learning core AZ-104 concepts through practical configuration and management tasks inside Microsoft Azure.

As additional AZ-104 objectives are studied, new labs, configurations, and documentation will continue to be added to this project.

---

## Current Objectives Covered

* Microsoft Entra ID
* User Administration
* Group Administration
* Azure RBAC
* IAM (Identity and Access Management)
* Least Privilege Access

---

## Technologies Used

* Microsoft Azure
* Microsoft Entra ID
* Azure RBAC
* Azure IAM
* Security Groups

---

## Tasks Completed

* Created Azure users
* Configured user properties
* Created Security Groups
* Added and removed group members
* Assigned Azure RBAC permissions
* Configured role assignments inside IAM

---

## Key Concepts Learned

* Identity management
* Azure RBAC
* Least privilege access
* Subscription-level permissions
* Security Groups
* Enterprise access control
